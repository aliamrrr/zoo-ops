# Assets

- `fonts/`: Baloo 2, Nunito and JetBrains Mono (SIL Open Font License), from Fontsource.
- `logos/`: Redis, PostgreSQL, FastAPI and Python marks from Simple Icons (CC0 files, the marks
  themselves stay trademarks of their owners). Colored with each brand's official color.
- `game/`: gameplay captured by `../capture-game.mjs`. Not committed, it is large and reproducible.
  `before` is a zoo with no pattern built, `after` is the same zoo once level 1 passes.
