# Code of conduct

Zoo Ops is a place to learn, so questions at every level are welcome and nobody is made to
feel slow for asking them.

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good intent, critique code and ideas rather than people, and keep
discussions on topic.

Unacceptable behavior can be reported privately to the maintainer through
[GitHub's private reporting](https://github.com/aliamrrr/zoo-ops/security/advisories/new) or
the contact links in the README. Reports are kept confidential.
